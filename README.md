# Houyi Blogs

Personal AI/AGI research blog for paper explainers, project notes, and bilingual technical writing.

## Direction

- AstroPaper-inspired visual system with a custom research-flow homepage.
- GitHub Pages deployment at `https://houyi.blog/`.
- Full bilingual site: English and Chinese posts, navigation, labels, search text, and article metadata.
- Markdown/MDX-first publishing workflow.
- Pagefind static search.
- Giscus comments via GitHub Discussions.

## Local Commands

```bash
npm install
npm run dev
npm run build
```

## Writing Workflow

Drafts are written inside the paper or project repository where the factual context lives. After review, a post is promoted into this blog repository with a standard metadata block and copied assets.

The first import tool will be built after the first real `blogs.md` is ready.
